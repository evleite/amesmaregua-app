Política de Privacidade

Aplicativo “A Mesma Regua” · Última atualização: 11 de outubro de 2026

1. O que é este aplicativo

“A Mesma Regua” é uma ferramenta interna do canal A Mesma Régua no YouTube. Ela é usada só pelo responsável pelo canal, para enviar e agendar os vídeos do próprio canal e conferir como ficaram publicados. O aplicativo não é oferecido ao público e não acessa contas de outras pessoas.

2. Uso dos Serviços de API do YouTube

Este aplicativo usa os Serviços de API do YouTube. Ao usá-lo, você concorda com os Termos de Serviço do YouTube. O tratamento de dados pelo Google segue a Política de Privacidade do Google.

3. Quais dados o aplicativo acessa

Com a autorização da conta (OAuth), o aplicativo pede só estas permissões:

  • Enviar vídeos ao YouTube (youtube.upload): para enviar os vídeos do canal e as capas deles.
  • Ver a conta do YouTube (youtube.readonly): para confirmar que a conta autorizada é o canal A Mesma Régua, conferir o status dos vídeos enviados (título, privacidade e data de publicação) e ler os números públicos do próprio canal (inscritos e views, curtidas e número de comentários de cada vídeo).
  • Ver relatórios do YouTube Analytics (yt-analytics.readonly, só leitura): para acompanhar o desempenho dos vídeos do próprio canal, como tempo de exibição, duração média assistida e inscritos ganhos.
  • Ler os comentários do canal (youtube.force-ssl): o Google só libera a leitura dos comentários do próprio canal por esta permissão, que em tese também permitiria gerenciá-los. O aplicativo a usa só para ler os comentários públicos dos vídeos do próprio canal (nome público do autor, texto e data) e listar os que ainda não foram respondidos.

O aplicativo não publica, responde, curte, oculta nem apaga comentários e não edita vídeos: qualquer resposta é escrita pelo responsável, diretamente no YouTube.

O aplicativo não acessa mensagens, a lista de inscritos, outros canais, contatos, e-mail nem outros serviços do Google.

4. Como os dados são usados e guardados

  • Os tokens de acesso ficam só no computador do responsável pelo canal, em arquivos com acesso restrito. O aplicativo não tem servidor nem banco de dados.
  • Para cada vídeo enviado, o aplicativo grava no mesmo computador um registro de produção: ID e link do vídeo, título, data de publicação e uma impressão digital (hash) do arquivo enviado.
  • Uma vez por dia, o aplicativo grava no mesmo computador um resumo dos números do canal e a lista de comentários ainda sem resposta, usados só pelo responsável para planejar os vídeos e responder aos comentários.
  • O nome do autor e o texto dos comentários são apagados desses registros em até 30 dias. Os números do canal ficam no histórico de desempenho do próprio canal.
  • Os dados são usados só para publicar, conferir e acompanhar os vídeos do próprio canal.
  • Nenhum dado é vendido, alugado ou compartilhado com terceiros. O aplicativo não exibe anúncios, não usa cookies e não faz rastreamento.

5. Como revogar o acesso e apagar os dados

  • Pela página de configurações de segurança do Google, onde é possível remover o acesso do aplicativo “A Mesma Regua” a qualquer momento.
  • Pelo próprio aplicativo, com o comando revogar (envio de vídeos ou métricas), que cancela a autorização no Google na hora e apaga o token local.
  • Depois da revogação, os dados de acesso guardados pelo aplicativo são apagados em até 7 dias (revogação pelo aplicativo) ou 30 dias (revogação pela página do Google).
  • Os registros de produção descritos no item 4 dizem respeito aos vídeos do próprio canal e são mantidos pelo responsável pelo canal, que é o único usuário do aplicativo.

6. Crianças

O aplicativo não é direcionado a crianças e não coleta dados de crianças.

7. Alterações

Mudanças nesta política são publicadas nesta página, com a data de atualização no topo.

Summary in English

“A Mesma Regua” is an internal tool used only by the owner of the A Mesma Régua YouTube channel to upload and schedule the channel’s own videos. It uses YouTube API Services; by using it you agree to the YouTube Terms of Service, and the Google Privacy Policy applies. It requests only youtube.upload, youtube.readonly, yt-analytics.readonly (read-only) and youtube.force-ssl, the latter used only to read public comments on the channel’s own videos and list unanswered ones (it never posts, replies to, hides or deletes comments, and never edits videos), stores the OAuth tokens locally on the owner’s computer, keeps a local record of each uploaded video and a daily summary of the channel’s numbers (comment authors and texts are deleted within 30 days), and does not share, sell or use data for ads, cookies or tracking. Access can be revoked at any time on the Google security settings page or with the app’s revogar command. Contact: evleite@gmail.com.
